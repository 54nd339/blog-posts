A [finite automaton](/citadel/automata/regular-languages) cannot check that every `(` has a matching `)`, because balanced nesting needs a counter that grows without bound and a finite machine has no such counter. Add one piece of unbounded memory — a stack — and the languages you can recognise jump to the **context-free languages** (CFLs): the class that describes the nested structure of arithmetic expressions, `if/else` blocks, and the syntax of essentially every programming language.

CFLs are generated by **context-free grammars** and recognised by **pushdown automata**. This post builds both, shows they define the same class, and then maps the edge of that class — what CFLs are closed under (less than regular languages) and what you can decide about them (much less than regular languages).

## Context-free grammars

A grammar $G = (V, T, S, P)$ is **context-free** if every production has the form

$$A \rightarrow x, \qquad A \in V,\; x \in (V \cup T)^*$$

— a single variable on the left, any string of variables and terminals on the right. The name is literal: you may replace $A$ by $x$ no matter what surrounds $A$ in the current string.

Three examples, none of them regular:

- $S \rightarrow aSb \mid \lambda$ generates $\{a^n b^n : n \ge 0\}$.
- $S \rightarrow aSa \mid bSb \mid \lambda$ generates the even-length palindromes $\{ww^R : w \in \{a,b\}^*\}$.
- $S \rightarrow SS \mid aSb \mid bSa \mid \lambda$ generates the strings with equal numbers of `a`s and `b`s. The $S \rightarrow SS$ rule makes this grammar *non-linear* — a sentential form can hold two variables at once.

Every regular grammar is already a context-free grammar, so the regular languages are a proper subset of the CFLs.

### Derivations and parse trees

When a string has several variables, you choose which to expand. Fixing that choice gives a canonical derivation: a **leftmost derivation** always rewrites the leftmost variable, a **rightmost derivation** the rightmost. Both exist for every derivable string.

A **parse tree** (derivation tree) records the *structure* of a derivation while forgetting the order. Its root is $S$, interior nodes are variables, leaves are terminals or $\lambda$, and a node labelled $A$ with children $a_1 \dots a_n$ left to right corresponds to a production $A \rightarrow a_1 \dots a_n$. Reading the leaves left to right gives the **yield**. The yields of $G$'s parse trees are exactly $L(G)$; the yield of a partial tree rooted at $S$ is a sentential form.

### Ambiguity

A grammar is **ambiguous** if some string in its language has two or more distinct parse trees (equivalently, two distinct leftmost derivations). The stock example is

$$E \rightarrow E + E \mid E * E \mid (E) \mid a \mid b \mid c,$$

where `a+b*c` parses both as `(a+b)*c` and as `a+(b*c)`. A compiler needs one reading, so you fix it either by declaring precedence outside the grammar or by rewriting the grammar to bake precedence in:

$$E \rightarrow E + T \mid T, \qquad T \rightarrow T * F \mid F, \qquad F \rightarrow (E) \mid a \mid b \mid c.$$

This layered grammar admits only the `a+(b*c)` tree. The same trick — stratifying by binding strength — is how real language grammars stay unambiguous; the [expression-parsing post](/citadel/artificial-intelligence/grammar) works through a parser for exactly this grammar.

A CFL is **unambiguous** if *some* unambiguous grammar generates it, and **inherently ambiguous** if *every* grammar for it is ambiguous. $L = \{a^n b^n c^m\} \cup \{a^n b^m c^m\}$ is inherently ambiguous: a string $a^k b^k c^k$ is forced into two derivations, one per side of the union, and no grammar escapes it. Whether an arbitrary CFG is ambiguous, and whether two CFGs are equivalent, are both undecidable.

### Parsing

**Parsing** is finding a derivation (or reporting there is none) for a given string.

- **Exhaustive search** — enumerate all leftmost derivations of length 1, 2, 3, … — works but can run in exponential time, and without care about $\lambda$- and unit productions it may not terminate. Drop those production types and it terminates in $O(|P|^{2|w|})$.
- **CYK** is dynamic programming over substrings: it decides membership (and can build the parse) in $O(|w|^3)$, but needs the grammar in Chomsky Normal Form (below). The [CYK post](/citadel/artificial-intelligence/grammar) gives a runnable recogniser.
- **LL and LR parsers** run in linear time on restricted grammar classes and are the workhorses of [compiler front ends](/citadel/compiler-design/syntax-analysis).

## Cleaning up a grammar

Proofs and algorithms want grammars without dead weight. For a $\lambda$-free language you can remove three kinds of production without changing $L(G)$ (add $\lambda$ back afterwards with a fresh start symbol $S_0 \rightarrow S \mid \lambda$):

1. **$\lambda$-productions.** A variable is **nullable** if $A \Rightarrow^* \lambda$. Find all nullable variables, then for each production add every version of it with some subset of its nullable symbols deleted — but never add $A \rightarrow \lambda$ itself. Result: no $\lambda$-productions, language unchanged except for $\lambda$.
2. **Unit productions** $A \rightarrow B$. Find every pair with $A \Rightarrow^* B$ through unit productions only; for each such pair, copy $B$'s non-unit productions onto $A$; then drop the unit productions.
3. **Useless productions.** A variable is useless if it cannot derive any terminal string, or is unreachable from $S$. Compute the variables that *can* derive a terminal string (bottom-up), discard the rest, then compute the variables reachable from $S$ and discard the rest. Order matters: terminating-check first, reachability second.

Apply them in the order $\lambda$ → unit → useless and you get an equivalent grammar with none of the three.

## Normal forms

### Chomsky Normal Form

Every production is $A \rightarrow BC$ (two variables) or $A \rightarrow a$ (one terminal). Every $\lambda$-free CFL has an equivalent CNF grammar, reached in two steps from a clean grammar:

1. **Isolate terminals.** In any right-hand side of length $\ge 2$, replace each terminal $a$ with a new variable $B_a$ and add $B_a \rightarrow a$. Now long right-hand sides are all variables.
2. **Break up long right-hand sides.** Replace $A \rightarrow C_1 C_2 \dots C_n$ ($n > 2$) with a chain $A \rightarrow C_1 D_1$, $D_1 \rightarrow C_2 D_2$, …, $D_{n-2} \rightarrow C_{n-1} C_n$ through fresh variables $D_i$.

CNF is what CYK needs, and its bounded right-hand sides are what make the CFL pumping lemma's tree argument go through.

### Greibach Normal Form

Every production is $A \rightarrow a x$ with $a$ a terminal and $x$ a (possibly empty) string of variables. Every $\lambda$-free CFL has one; the conversion is fiddlier, involving left-recursion removal and substitution. Its value: each leftmost derivation step emits exactly one terminal, which lines the grammar up cleanly with a pushdown automaton.

## Pushdown automata

A **pushdown automaton** is a finite control with a read-only input and one **stack** of unbounded depth. The nondeterministic version (NPDA) is a 7-tuple $M = (Q, \Sigma, \Gamma, \delta, q_0, z, F)$: states $Q$, input alphabet $\Sigma$, stack alphabet $\Gamma$, start state $q_0$, initial stack symbol $z$, accepting states $F$, and

$$\delta : Q \times (\Sigma \cup \{\lambda\}) \times \Gamma \rightarrow \text{finite subsets of } Q \times \Gamma^*.$$

A transition $(p, \gamma) \in \delta(q, a, b)$ reads: in state $q$, reading input $a$ (or nothing if $a = \lambda$), with $b$ on top of the stack, you may move to state $p$, pop $b$, and push the string $\gamma$.

An **instantaneous description** $(q, w, u)$ is the current state, unread input, and stack contents (top at the left). A move is $(q_1, aw, bx) \vdash (q_2, w, \gamma x)$ when $(q_2, \gamma) \in \delta(q_1, a, b)$, and $\vdash^*$ is any number of moves. $M$ **accepts** $w$ (by final state) if $(q_0, w, z) \vdash^* (p, \lambda, u)$ for some $p \in F$ and any stack $u$. Accepting "by empty stack" instead gives the same class of languages.

For $\{a^n b^n : n \ge 0\}$: push a marker for each `a`, pop one for each `b`, and accept when the input is exhausted and the stack is back to just $z$.

An NPDA is **deterministic** (a DPDA) if $|\delta(q, a, b)| \le 1$ everywhere and a $\lambda$-move and an input-consuming move are never both available from the same $(q, b)$. The languages DPDAs accept — the **deterministic CFLs** — are a *proper* subset of the CFLs. Palindromes $\{ww^R\}$ are context-free but not deterministic: the machine cannot tell where the middle is without guessing. This gap has no analogue for finite automata, where determinism is free.

## Grammars and PDAs define the same class

**Every CFL is $L(M)$ for some NPDA, and every NPDA's language is a CFL.**

*CFG → NPDA* (grammar in GNF): use a 3-state machine that keeps the pending variables of a leftmost derivation on its stack. Push $S$ to start ($\delta(q_0, \lambda, z) = \{(q_1, Sz)\}$). For each production $A \rightarrow a\,x_1 \dots x_k$, add $\delta(q_1, a, A) = \{(q_1, x_1 \dots x_k)\}$: read the terminal the rule produces, pop $A$, push the rest. Accept when the stack empties back to $z$.

*NPDA → CFG*: introduce variables $(q_i\,A\,q_j)$ meaning "some input drives $M$ from $q_i$ to $q_j$ with the net effect of popping $A$". A pop move $(q_j, \lambda) \in \delta(q_i, a, A)$ gives $(q_i\,A\,q_j) \rightarrow a$; a move that replaces $A$ with $BC$ gives $(q_i\,A\,q_k) \rightarrow a\,(q_j\,B\,q_l)(q_l\,C\,q_k)$ for all state choices $q_l, q_k$. The start variable is $(q_0\,z\,q_f)$. This mirrors the finite-automaton ↔ regular-grammar correspondence one level up.

## Closure: weaker than regular

CFLs are closed under **union, concatenation, Kleene star, homomorphism, and reversal** — each shown by splicing grammars or PDAs.

They are **not** closed under **intersection**: $\{a^n b^n c^m\}$ and $\{a^n b^m c^m\}$ are both context-free, but their intersection $\{a^n b^n c^n\}$ is not (next section). **Complement** fails too, by De Morgan — if CFLs were closed under complement and union they would be closed under intersection.

One useful special case survives: **the intersection of a CFL with a regular language is context-free**. Run the PDA and a DFA for the regular language in parallel, pairing their states; the stack is untouched, so it is still a PDA.

## The pumping lemma for context-free languages

The finite-automaton argument becomes a statement about tall parse trees. In a CNF grammar, a parse tree for a long string must have a root-to-leaf path long enough that some variable $A$ repeats on it. The derivation then looks like $S \Rightarrow^* uAz \Rightarrow^* uvAyz \Rightarrow^* uvxyz$, and the middle segment $A \Rightarrow^* vAy$ can be repeated or skipped.

**Pumping lemma (CFL).** For every CFL $L$ there is a constant $m \ge 1$ such that every $w \in L$ with $|w| \ge m$ splits as $w = uvxyz$ with $|vxy| \le m$, $|vy| \ge 1$, and $uv^i x y^i z \in L$ for all $i \ge 0$.

The proof caps $|vxy|$ by bounding the height of a subtree with no repeated variable; $|vy| \ge 1$ needs the grammar free of $\lambda$-, unit, and useless productions. The adversary game is the same as for regular languages, but the adversary has more freedom — only $|vxy| \le m$ constrains the split — so you must defeat every placement of the window.

$L = \{a^n b^n c^n : n \ge 0\}$ is not context-free. Pick $w = a^m b^m c^m$. Because $|vxy| \le m$, the window $vxy$ touches at most two of the three letter blocks, so pumping to $i = 2$ throws the counts out of balance — either the untouched block falls behind, or a "$vy$ spans two blocks" split scrambles the order. Every case contradicts membership. The same lemma rules out $\{ww : w \in \{a,b\}^*\}$, $\{a^{n!}\}$, and $\{a^n b^j : n = j^2\}$.

## Decision problems: much is now undecidable

| Question about a CFG $G$ | Status |
| --- | --- |
| $w \in L(G)$? | decidable (CYK) |
| $L(G) = \emptyset$? | decidable (can $S$ derive any terminal string?) |
| $L(G)$ infinite? | decidable (a useful variable on a cycle) |
| Is $G$ ambiguous? | **undecidable** |
| $L(G_1) = L(G_2)$? | **undecidable** |
| $L(G_1) \subseteq L(G_2)$? | **undecidable** |
| Is $L(G)$ regular? | **undecidable** |
| $L(G_1) \cap L(G_2) = \emptyset$? | **undecidable** (reduction from the Post Correspondence Problem) |
| $L(G) = \Sigma^*$? | **undecidable** |

Compare the [regular-language table](/citadel/automata/regular-languages), where equality, inclusion, and the rest are all decidable. Adding the stack bought nested structure and cost you the ability to reason about the languages in general — a trade that continues all the way up to [Turing machines](/citadel/automata/turing-machines), where even membership stops being decidable.

## The one idea to keep

A stack is exactly the memory you need for nesting, and no more: context-free grammars and pushdown automata both capture it, and they capture the same class. But the stack is also where the clean theory ends. Nondeterminism now matters ($\{ww^R\}$ needs it), intersection and complement escape the class, and almost every interesting question about an arbitrary CFG — is it ambiguous, does it match another grammar, is its language actually regular — has no algorithm at all.
